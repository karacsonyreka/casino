# Cassino

The Hungarian two-player version of Cassino, with a 52-card French deck —
you against the computer, in the browser.

## Play in the browser

```sh
uv run python server.py
```

Starts a local server and opens the table at `http://127.0.0.1:8000/`.
Leave the terminal running while you play; `Ctrl+C` stops it.

## Run the tests

```sh
uv run pytest
```
